# Szia, Máté vagyok! 👋

**AI fejlesztő, LLM mérnök, Fullstack fejlesztő és DevOps mérnök**  
8+ év Java- és Spring-alapú fejlesztési tapasztalattal rendelkezem banki, állami és vállalati projektekben.

AI-alapú alkalmazásokat fejlesztek, nagy nyelvi modelleket integrálok és AI-ágensekre épülő munkafolyamatokat alakítok ki. További fő területeim a skálázható backendek, a CI/CD, a konténerizáció, az orchesztráció, valamint a hitelesítés és jogosultságkezelés. Tapasztalatom van frontendfejlesztésben, Jira-bővítmények fejlesztésében, DevOps-automatizációban és alkalmazásüzemeltetésben is.

**Frontend:** React, Angular, TypeScript, RxJS, JavaScript, JSF, JSP, PrimeFaces  
**Adatbázisok és migrációk:** Oracle SQL, PL/SQL, MySQL, PostgreSQL, MSSQL, MongoDB, H2, Redis, Liquibase, Flyway  
**Konténerek és orchesztráció:** Docker, Kubernetes (k3s, RKE2), Rancher, Helm  
**CI/CD és szoftverszállítás:** GitHub Actions, GitLab CI, GitLab Runner, Jenkins, Azure DevOps, Nexus  
**GitOps és infrastruktúra-automatizáció:** Argo CD, Ansible, Terraform  
**Felhőplatformok:** Microsoft Azure, Amazon Web Services (AWS), Google Cloud (GCP)  
**Hitelesítés és jogosultságkezelés:** Keycloak, WSO2, Spring Security  
**Monitorozás és naplózás:** Prometheus, Grafana, ELK  
**Rendszerek és szkriptelés:** Linux (Ubuntu, Debian), Windows, Nginx, Bash, PowerShell, Python  
**Minőségbiztosítás, API-dokumentáció és tesztelés:** SonarQube, Checkmarx, JaCoCo, JMeter, Postman, OpenAPI, SoapUI  
**Verziókezelés és együttműködés:** Git, GitLab, SVN, Jira, YouTrack, Redmine, Scrum

## 🧠 Autodidakta tanulás

Folyamatos fejlődés önálló tanulással és gyakorlati tapasztalatszerzéssel.

**AI-eszközök és lokális modellek:** Claude Code, ChatGPT, Cursor, lokális AI-modellek futtatása  
**AI-alkalmazásfejlesztés:** LLM-integráció, prompt- és kontextustervezés, beszélgetési memória, strukturált kimenetek, tool calling és Model Context Protocol (MCP)
